# Discord is for urgent, perishable actions only

Discord had become a mix of urgent alerts, nightly summaries and digests. We decided a Discord message is only for something that may not last and needs action: DealFinder deals, supplier price drops, SourceWatch price-back alerts, top-ups whose timing says order now, and pipeline failures. Everything else (best offers, night pre-screen results, post-mortems, the sources report, the ungating digest, routine stage summaries) lives on a Dashboard tab. Every message says what to do.

**Consequences.** One drop must never ping twice: when DealFinder's Qogita feed (067) starts posting, alchemist-v2's 064 alerts switch off the same day. A new feature that wants a Discord message has to show it is urgent and perishable.
